# JMD GBP client report + follow-up issue lessons

Session context: JMD-2 Google Business Profile audit was converted into a client-facing HTML presentation and Linear follow-up issues.

## Client-facing report guidance
- Audience is Lucky and Danny, not an internal operator. Write directly to owners in plain business language.
- Report should be specific about:
  - what is already working,
  - what needs fixing,
  - which owner approvals are needed,
  - how the fixes translate into more calls, directions, website clicks, and store visits.
- Avoid generic audit phrasing like "profile completeness opportunity" unless paired with concrete fixes.
- Keep the tone practical and local: JMD already has demand; the job is to turn more searchers into store visitors.
- Combine owner approvals into one "owners need to approve" checklist rather than splitting Lucky and Danny into separate boxes unless the user explicitly asks for role separation.
- Be careful not to overstate review-response work: JMD had only a few unanswered reviews, so frame it as light trust cleanup, not a major search-proof initiative.
- Be specific about evidence: the hours inconsistency came from YellowPages, so name YellowPages rather than saying "one directory" generically.

## GBP Q&A / Ask Maps guidance
- Traditional Google Business Profile Q&A should not be treated as the primary 2026 quick-fix surface.
- Google discontinued the My Business Q&A API on Nov. 3, 2025; user-facing Q&A behavior is shifting toward AI-driven answer experiences such as Ask Maps.
- For JMD, the stronger strategy is to improve answer sources:
  - complete GBP description, services, attributes, products, photos, and posts,
  - website FAQ content with FAQ schema where appropriate,
  - customer reviews that naturally mention specific use cases,
  - monitoring visible AI/Ask Maps answers for accuracy.

## Supercharging GBP action rates
When planning growth beyond profile cleanup, focus on profile-view conversion:
- Website click rate = website clicks / profile views.
- Direction request rate = direction requests / profile views.
- Call rate = calls / profile views.
- Combined action rate = website clicks + direction requests + calls / profile views.

Practical tactics for JMD:
- UTM-tag GBP website, product, and post links.
- Test whether GBP should link to homepage, Conyers landing page, or fitting/appointment page.
- Ensure landing page has call and directions above the fold on mobile.
- Add storefront, shopping-center, exterior, interior, product, fitting, and seasonal photos.
- Keep hours and special hours accurate, especially around prom/wedding/holiday seasons.
- Replace stale product references such as "Fall 2019" with current approved product/service categories.
- Publish weekly GBP posts, 2/week during prom/wedding season if real photo inventory supports it.

## Follow-up Linear issue set from JMD-2
Suggested issues created after GBP audit:
1. Implement approved Google Business Profile quick fixes.
2. Benchmark local SEO and GBP competitors.
3. Clean up conflicting hours citations, starting with YellowPages.
4. Plan and capture real JMD photos for GBP refresh.
5. Catch up on unanswered Google review responses.
6. Build plan to increase GBP website click and direction-request rates.

Each issue should include context, goal, recommended approach, constraints, acceptance criteria, and approval gates.
