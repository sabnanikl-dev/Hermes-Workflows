# Hermes Personal Product 001 — Direct Buyer-Voice Lead Mapping Pattern

Use this reference during Hermes Personal passive-revenue scout runs when Product 001 still has a direct buyer-demand gap for the **pack buyer**: AI automation freelancers or tiny agencies.

## Trigger

Apply this when the source map has market-adjacent evidence but still lacks direct freelancer/agency buyer-voice proof, especially after an adversarial reviewer flags that local-business pain is being mistaken for pack-buyer demand.

## Core distinction

Separate three evidence levels:

1. **End-business pain** — local service businesses miss calls, follow-ups, or inquiries.
2. **Market-adjacent pack signals** — marketplaces, playbooks, templates, prices, ratings, or methodology sources showing people buy packaged AI/automation know-how.
3. **Direct pack-buyer voice** — freelancers/agencies saying in their own words that they struggle with discovery calls, proof, objection handling, client acquisition, offer validation, or sales-call process.

Only level 3 can close the direct buyer-voice gate.

## If source pages are blocked

When search results surface relevant Reddit/forum/community snippets but source pages are inaccessible (403, login wall, unsupported extraction, bot challenge):

- Do **not** count snippets as full citation proof.
- Do **not** mark the direct buyer-voice evidence gate complete.
- Add a clearly labeled lead-map section, e.g. `Direct pack-buyer voice leads — initial map, not a passed gate`.
- Treat snippets as **research leads** that narrow the next evidence pass.
- Log the experiment decision as `hold`, not `promote`.

Good caveat wording:

```md
Because source pages returned 403 blocks through the available extract/browser paths, these snippets are treated as research leads, not full citation proof. The direct buyer-voice gate stays unchecked until accessible public pages, alternate mirrors, or non-Reddit sources provide verifiable body/comment quotes.
```

## Evidence table shape

```md
| Source | Observable buyer-language lead | What it supports | Caveat |
|---|---|---|---|
```

Useful lead types:

- “first sales call” / “any tips” posts from new AI agency owners;
- agency/freelancer threads about few clients, objections, client acquisition, or offer validation;
- voice-AI/automation sellers asking how to sharpen on-call process;
- small-business skepticism snippets that reveal objections the freelancer must handle;
- direct quotes from freelancers/agencies once accessible.

## Experiment ledger pattern

Surface: `product format`

Primary metric: `source-map support count`

Decision:

- `hold` when leads are mapped but full source bodies/quotes are inaccessible or insufficient;
- `promote` only when the run adds enough direct, accessible, quote-level buyer-voice evidence and maps it to product artifacts;
- `blocked` only when no repo-local research path remains.

Example result:

```text
5 public search-result/thread leads mapped; source pages blocked, so gate remains unchecked
```

## Boundaries

Do not contact posters, send outreach, scrape private communities, use private/client data, publish the map externally, or claim buyer demand from snippets. Public-live actions still require Karan approval.
