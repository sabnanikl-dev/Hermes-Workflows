# Hermes Personal: freelancer sales-objection evidence map

Use this when Product 001 / a passive-revenue scout is blocked on direct buyer proof but finds accessible sales-friction sources.

## Durable lesson

When NotebookLM and/or an adversarial reviewer identifies a buyer-proof gap, do not treat vendor/expert/end-buyer articles as direct buyer voice just because they are relevant. They can improve the objection map, but the launch gate stays blocked until accessible quote-level buyer sources exist.

## Pattern

1. Query the required NotebookLM notebooks separately and synthesize outside NotebookLM.
2. If the AI-money notebook recommends a “gold mine” / buyer-objection map, inspect bounded public sources.
3. Classify sources honestly:
   - **Direct buyer voice**: freelancer/agency/community/review language in the buyer’s own words. Counts toward the gate when accessible and quote-level.
   - **Sales-friction support**: vendor/expert/end-buyer articles naming objections, discovery-call methods, template categories, price anchors, or proposal red flags. Useful, but does not pass the direct buyer-voice gate.
   - **Search snippets / blocked threads**: leads only; do not count as proof.
4. Update the product source map with a section like `Freelancer sales-objection evidence — accessible but not direct buyer voice`.
5. Map each source to: observable evidence, kit implication, caveat.
6. Update the proof map/source notes if one exists.
7. Log exactly one experiment row. Use `hold` if the work improved support count/objection coverage but did not pass direct buyer voice.

## Example metric

Primary metric: `source-map support count`

Result wording:

```text
5 accessible sales-friction sources mapped to kit artifacts; direct buyer-voice gate still 0/3 passed.
```

Decision: `hold`

## Pitfalls

- Do not let accessible vendor articles quietly become “buyer proof.”
- Do not ask for public listing/checkout approval while the direct buyer-voice gate is still unchecked.
- Do not rebuild/export public-facing artifacts just because the objection map improved; that is a separate product surface.
- Do not copy raw NotebookLM/adversarial prose into buyer-facing copy; distill into repo-local evidence docs.
