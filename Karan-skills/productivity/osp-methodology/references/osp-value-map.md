# OSP Product/Service Value Map Generator

Based on [Open Strategy Partners](https://openstrategypartners.com) methodology.

## When to load this skill

- Creating a value map deliverable for a Papi AI Consulting client
- Formalizing Femme Events positioning against competitors
- Developing taglines, position statements, or persona docs for any business
- Building a feature/benefit hierarchy for a product or service
- Preparing content for pitch decks, proposals, or website copy

## Required output components

### 1. Taglines
- Short, impactful statements capturing the core value
- No bullet points — direct statements
- Generate 3-5 options, mark your recommended one
- Example: *"Elegant wedding coordination that lets you actually enjoy your own day"*

### 2. Position Statements (4 dimensions)
- **Primary market position**: Who you serve and why you're different
- **Technical/methodology position**: Your approach or process advantage
- **Experience position**: What working with you feels like
- **Business value position**: Tangible outcomes (time saved, stress reduced, revenue gained)

### 3. Personas
Each persona must include:
- Role and responsibilities
- Key challenges / pain points
- Primary needs
- How the product/service addresses them
- Emotional drivers (what keeps them up at night)

### 4. Value Cases
Each case follows:
- **Benefit**: Clear outcome or advantage
- **Challenge**: Problem being solved
- **Solution**: How the product/service addresses it
- Link to a persona where possible

### 5. Feature Categories (hierarchical)
Organize into 4 required categories:
1. **Core Capabilities** — primary functions, key features, core workflows
2. **Technical/Process Implementation** — methodology, tools, integrations, systems
3. **Operational Benefits** — efficiency gains, time savings, management advantages
4. **Business Value** — cost benefits, risk reduction, growth enablement, ROI

Each category → feature areas → specific features → supporting facts/evidence

## Generation process

1. **Research** — Gather existing docs, website copy, competitor analysis, client interviews
2. **Analyze** — Identify core value propositions, map features to benefits, spot gaps
3. **Structure** — Build the hierarchy, define personas, document value cases
4. **Write** — Draft taglines, position statements, persona descriptions, value cases
5. **Validate** — Check completeness, verify relationships, ensure consistency

## Validation checklist

- [ ] All 5 components present
- [ ] Taglines are specific (not generic platitudes)
- [ ] Position statements cover all 4 dimensions
- [ ] Personas include emotional drivers, not just functional needs
- [ ] Value cases link benefits → challenges → solutions clearly
- [ ] Feature hierarchy has facts/evidence supporting claims
- [ ] Language is active voice, benefit-focused, specific

## Business-specific notes

### For Papi AI Consulting clients
- Adapt category names to the client's domain (e.g., "Technical Implementation" for SaaS, "Service Delivery" for professional services)
- Include competitive differentiation in position statements
- Value cases should reference real client outcomes when available
- This is often the primary deliverable — make it presentation-ready

### For Femme Events
- Emphasize emotional/experiential positioning (weddings are emotional purchases)
- Competitors: Emily Jordan Events, Wrennwood, Gloria Schulz, Tinted Events, S&B Events, Lemiga, Evermore, Jackson & June
- Key differentiator: Coordination + design under one roof (Karan + Amanda partnership)
- Personas should include: engaged couples, corporate event planners, luxury brides on a budget
