# OSP Content Editor

Based on [Open Strategy Partners](https://openstrategypartners.com) writing guidelines.

## When to load this skill

- Reviewing website copy for Femme Events or consulting clients
- Editing proposals, pitch decks, or client deliverables
- Polishing email campaigns or social media copy
- Reviewing any marketing or business content before publishing
- When Karan says "review this" or "edit this" for business content

## Review protocol

1. **Read** the full content first — understand thesis, audience, domain
2. **Structure analysis** — check narrative flow, logical progression, missing elements
3. **Technical review** — verify claims, check terminology, validate specifics
4. **Language optimization** — apply style guidelines, improve clarity, enhance readability
5. **Feedback format** — show all changes in diff format, use codes for categorization
6. **Positive reinforcement** — use `++` prefix for praise
7. **Deliver** the full edited text at the end

## Editing codes reference

### A. Scope & Narrative Structure
| Code | Meaning |
|------|---------|
| LEDE | Present main point first (no buried leads) |
| FRONT | State primary idea clearly upfront |
| SPFIC | Use specific scenarios over vague claims |
| WHOM | Identify target audience early |
| WIIFM | Lead with audience benefits ("What's in it for me") |
| POINT | Evaluate argument support strength |
| SPOCK | Ensure logical consistency, avoid fallacies |
| FACT | Support claims with evidence |
| CTA | Clear action directive |
| SUMM | Benefit-focused summary |
| THESIS | Restate main idea (not verbatim) |

## Feedback format

Always show changes as numbered diffs:
```diff
1.
- Original text with issue
+ Improved version addressing issue
```

Prefix praise with `++`:
```
++[WIIFM] Great benefit-led opening — immediately answers "why should I care?"
```

## Writing principles (apply during edits)

- **Active voice** — "The system processes the file" not "The file was processed"
- **Direct address** — "You can configure..." not "Users can configure..."
- **Specific** — "Kubernetes automates container deployment" not "Many tools help with deployment"
- **Concise** — "To implement this" not "In order to implement this functionality"
- **Sentence case** for headers — "My great header" not "My Great Header"
- **Benefit-focused** — lead with outcomes, not features

## Content type considerations

### Website copy (Femme Events)
- Emotional resonance matters — weddings are feelings-first purchases
- Use sensory language, paint the picture
- Keep paragraphs short (mobile readers)
- Strong CTAs: "Start planning your day" not "Contact us"

### Proposals & pitch decks (Papi AI Consulting)
- Lead with the client's problem, not your solution
- Quantify everything possible (time saved, revenue gained)
- Use the value map structure to organize deliverables sections
- Professional but not corporate — match Karan's tone

### Email campaigns
- Subject line = meta title rules (under 60 chars, front-loaded)
- First line = LEDE code (main point immediately)
- Single clear CTA
- Keep under 200 words for outreach emails

### Social media copy
- Hook in first 5 words
- One idea per post
- End with engagement prompt or CTA
- For Instagram: visual-first, copy supports the image
