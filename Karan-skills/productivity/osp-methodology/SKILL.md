# OSP Methodology

## Overview

This is the umbrella skill for Open Strategy Partners-style business communication work: value maps, positioning, marketing copy, editorial review, and on-page SEO. Use it when the user needs a strategic content deliverable, not just generic writing.

Core values: **Empathy, Clarity, Trust**. The output should make the audience, value, proof, and next action obvious.

## When to Use

- Creating a product/service value map, personas, value cases, or positioning statements
- Writing website copy, proposals, pitch narratives, service descriptions, email campaigns, or social content
- Reviewing or editing marketing/business content before publishing
- Producing SEO metadata, slugs, titles, descriptions, or structured-data recommendations
- Preparing content for Femme Events, Papi AI Consulting, or a client deliverable

## Workflow

1. **Clarify the deliverable class**: value map, net-new copy, edit/review, SEO optimization, or combined content package.
2. **Collect audience and offer context**: who it serves, pain points, proof points, competitors, desired action, channel constraints.
3. **Choose the subsection below** and follow its checklist.
4. **Make the output usable**: include final copy or tables, not just advice.
5. **Flag assumptions** when audience, search intent, or offer details are missing.

## Value Map Subsection

Use for strategy/positioning deliverables. Include:

- Taglines or concise promise statements
- Positioning statements across audience, problem, outcome, and differentiation
- Personas with pains, jobs-to-be-done, objections, and success criteria
- Value cases connecting features to business/user outcomes
- Feature/benefit hierarchy suitable for website copy, proposals, or sales collateral

## Marketing Copywriting Subsection

Use for creating net-new copy. Protocol:

1. Research the audience, competitive frame, proof points, and constraints.
2. Draft with a clear narrative arc: problem → stakes → solution → proof → CTA.
3. Prefer concrete nouns and verbs over abstract hype.
4. Keep claims proportional to evidence.
5. Deliver copy in the requested format: page sections, email sequence, social calendar, deck narrative, etc.

## Content Editing Subsection

Use for reviewing existing content. Protocol:

- Read the full content before editing.
- Identify structural issues before wordsmithing.
- Use concise labeled feedback for scope, narrative, flow, style, word choice, proof, and CTA.
- Provide revised copy or diff-style replacements for the highest-impact fixes.

## SEO Optimization Subsection

Use for pages/posts that need search visibility. Provide:

- Article/page title
- Meta title and meta description
- URL slug
- Primary and secondary keywords/search intents
- H1/H2 recommendations
- Internal-link suggestions
- Structured-data recommendation when applicable

## Common Pitfalls

1. **Generic AI marketing copy.** Avoid vague superlatives and empty claims; tie each claim to a value case or proof point.
2. **SEO without intent.** Metadata should match the searcher's problem and page content, not just stuff keywords.
3. **Editing before strategy.** If the positioning is wrong, fix the frame before polishing sentences.
4. **Mixing audiences.** Keep each page or deliverable focused on one primary buyer/user context.

## Verification Checklist

- [ ] Deliverable type is clear: value map, copy, edit, SEO, or combined
- [ ] Audience, offer, proof, and CTA are explicit
- [ ] Output contains ready-to-use text/tables, not only advice
- [ ] Claims are specific and supportable
- [ ] SEO fields are included when search visibility is part of the ask
