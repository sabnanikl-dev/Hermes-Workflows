# Baoyu Visual Storytelling

## Overview
Use this umbrella for Baoyu-style visual knowledge work: article hero/inline illustrations, educational comics, and information-dense infographics. The shared class is visual explanation with consistent prompt systems, style palettes, and layout choices.

## When to Use
- Create article illustrations with type × style × palette consistency.
- Turn a concept, biography, or tutorial into an educational comic.
- Build an infographic from structured or research content.

## Subworkflows

### Article illustrations
Classify the article's core idea, choose visual metaphor and palette, then construct image prompts that preserve the publication's style system.

### Knowledge comics
Pick the pedagogical form: explainer, biography, tutorial, or narrative. Define panel sequence, characters, tension, and visual continuity before generating assets.

### Infographics
Normalize the source into claims, metrics, comparisons, timelines, or processes. Choose layout based on information structure, then apply style and palette rules.

## Package References
The detailed legacy prompt libraries, styles, layouts, and templates were re-homed under `references/absorbed/<skill-name>/`.

## Verification Checklist
- [ ] Match output type to the knowledge structure.
- [ ] Keep palette/style internally consistent.
- [ ] Preserve factual claims and uncertainty.
- [ ] Verify generated prompts are specific enough for reproducible visual direction.
