# Generative Media Production

## Overview
Use this umbrella for generating or manipulating creative media artifacts: ASCII art/video, Manim animations, pixel art, ComfyUI workflows, TouchDesigner scenes, and songwriting/AI music prompts.

## When to Use
- Convert images/video/audio into ASCII output.
- Create Manim explainer animations.
- Generate pixel art or pixel-art videos.
- Build ComfyUI image/video/audio workflows.
- Control TouchDesigner scenes through MCP.
- Draft songs or music-generation prompts.

## Workflow
1. Clarify medium, output format, aspect/duration/resolution, and style constraints.
2. Choose the production tool: CLI script, Manim, browser/HTML, ComfyUI, TouchDesigner, or music prompt.
3. Generate a real artifact or verified prompt package.
4. Inspect the output visually/audibly or with file metadata.
5. Return the artifact path/URL and parameters used.

- [ ] Output file or live scene exists.
- [ ] Parameters and dependencies are recorded.
